# 萤光山径素材

家长选择青绿秘境参考后，以内置图像生成（ImageGen）重新制作适合分层的运行素材。没有使用第三方摄影图片或新增网络图片服务。

- `forest-trail.webp`：1448×1086，山路、远山和远处小门；中央留空供门或写字区覆盖。
- `gate-frame.webp`：540×720，藤花石门框，外部与门洞保持真实透明通道。
- `gate-doors.webp`：480×640，正面双扇木门，中心缝固定在50%；样式左右各取一半开合。

三图共490,000字节。原始PNG与生成提示词另存用户指定的本机成品目录，运行页仅引用这里的压缩素材。透明边缘不另裁切，门洞布局与完整3:4画布对应。

图片不进入汉字判分，不改变300×300书写坐标或教学计时。加载失败不阻止游戏启动与作答。
