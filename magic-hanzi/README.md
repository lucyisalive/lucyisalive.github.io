## 运行与构建

需要 Node.js 运行构建脚本。用 Python 启动本机预览，打开 `http://127.0.0.1:8876/`。

```sh
node tools/build-page.cjs
python3 -m http.server 8876 --bind 127.0.0.1
```

离线单页包含场景、六枚袍子和现有 167 个字形。双击生成的文件可试玩。

```sh
mkdir -p work
node tools/build-offline-preview.cjs work/魔法闯关汉字游戏_十一关视觉试玩.html
```

云端副本以本机存档模式启动。开发和测试使用内置字库或模拟学习数据。内置参考字形源自汉字书写器字形数据（Hanzi Writer Data），字形许可证见 [ARPHICPL.TXT](ARPHICPL.TXT)。

发布前先构建，再运行 iPad 音频检查。开发仓库向 `main` 推送或发起合并请求时也会自动运行同一套检查。

```sh
node tools/build-page.cjs
node tools/check-audio-release.cjs
```

这些检查用模拟的浏览器音频服务验证点击朗读、语音恢复、快速判分和切换前后台。iPad 扬声器的实际输出由真机试听验证。

```sh
node tests/page-build.cjs
node tests/offline-startup.cjs
node tests/herbalist-room-integration.cjs
node tests/parent-priority.cjs
```

## 已确认接入的四关

四关接在原七关之后。第八关沙丘寻龙沿十枚脚印唤醒无角龙，结尾从第一视角骑上龙背。第九关高塔禁书用十本朴素蓝布封面、棕皮书脊的藏书搭成台阶，红金禁书打开后，咒文与幽灵武士出现。第十关冰雪庭院让女神身上的冰壳逐步裂开融化，女神牵住第一视角孩子的手，带着孩子升入夜空。第十一关每通过一个字断开一整根缠绕盔甲的铁链，第十根断开后自动单膝跪地，胸甲与甲缝发光。

人鱼浮出水面、骑龙、打开禁书和牵手飞起的结尾会播放后停留，孩子看完再点「前往下一关」。盔甲停在单膝发光终态，孩子可点「回到草药房」。学习关卡只在正式通过时推进，观看演示使用独立进度，不写入学习记录或增加银币。

## 原七关中的后五关

每关十次正式通过。星象台之后依次进入以下场景。

3. **巨人厨房。** 星鸟把孩子领到山脚的巨人厨房。每正式通过一个字，巨人亲手把一样巨大的食材扔进锅里。第十样下锅后，孩子喝下巨人汤，长成巨人，到挡路的山前，一拳把山打碎。山后露出深渊断桥。
4. **深渊断桥。** 每正式通过一个字，一块桥板飞到绳索上。第十块补齐后，孩子从自己的视点走过吊桥，到对岸的小车站。
5. **气球火车。** 每正式通过一个字，车顶鼓起一个气球。十个气球全部鼓起后，列车升空并穿过云层，抵达墓穴入口。
6. **墓穴大厅。** 十种猛兽守在门前。活着时会伏身或逼近，眼光和火光一起闪动。每正式通过一个字，一只守卫化作静止的灰色石像。十只都石化后，孩子从中间走过去，推开石门并进入水底。
7. **水底人鱼。** 水底起初只有水光。每正式通过一个字，一个音符才出现并奏响。第十个音符出现后，人鱼伴着歌声游过来。镜头跟着她浮出水面，停留后由孩子点「前往沙丘寻龙」。

全程使用第一视角。巨人厨房用一扇正常尺寸的侧门和一把木凳作比例参照。喝汤前后以同一个窗台为参照，视线由仰看升到俯看。打山时从画面下方带出拳头。山崩后，尘雾散去时视线回到原来的高度，再踏上吊桥。

场景图片及生成提示词见 [故事素材](assets/story/README.md)。

## 午夜奇物铺与巫师房间

在顶部点“巫师小屋”，再点“去商店选购”，可查看全部 24 件商品及分类。选择一件可预览小魔法、看价格和余额，再确认兑换；差额、已拥有、保存失败都有清楚提示。兑换成功可直接回房间看，也可继续选购。

购买扣币、拥有记录与初次陈列一起原子保存，已拥有商品不重复扣币。现有古银币只迁移一次；每次正式通过仍得 1 枚，完整一关额外 5 枚，演示和教学中的单次写对不增加。失败的奖励有独立事件记录并可安全补存，刷新恢复或重复点重试不多发。

房间保留原有床、凳、窗和地板。大家具固定陈列，小物可在窗台、旧木箱、墙边架间移动，陈列选择刷新后保留；“我的藏品”可查看并点按所有已购商品。鸟 300、猫 1,000 独立出售。茶具、画像、箱子、鸟与猫使用相应动画及专用动作素材。

银币、藏品和摆放使用新版独立本机账本；学习云同步和旧版故事记录不加入商店数据。打开/关闭小屋不换题或清除笔迹。用浏览器数据库（IndexedDB）保存；缺少该能力时使用带浏览器锁的本机存储。读写失败不冒充成功、不覆盖坏档，界面提供重新读取与重试保存。完整素材与提示词见 [商品素材](assets/shop/README.md)。

新增验证：`node tests/magic-shop-catalog.cjs`、`node tests/magic-shop-ledger.cjs --browser-required`。既有音频发布检查同时执行商品和账本回归。
