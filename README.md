当前版本：**2026.11.03.6**。设置面板底部可查看版本。`index.html` 与 `汉字魔法门_4.html` 必须完全一致。继续使用原收藏，不需改网址或添加版本参数。

## 启动与发布

修改页面逻辑请编辑 `game-source.html`；模块仍编辑各自的 JS/CSS 源文件，随后运行 `node tools/build-page.cjs` 生成两个入口。不要直接改生成后的 HTML。`node tools/build-page.cjs --check` 检查发布页与源文件一致。

2026-11-03真机诊断发现：两个字形脚本各等待约100秒，导致界面先出现而按钮迟迟未注册。第一次整页内嵌修复未解决用户设备问题，并将首次传输量增大；随后改为轻量页面：只内嵌必要小模块与反馈样式，当前字及其原有部件按需读取同源小JSON，拼音大表仅在家长开始录入时加载。首次传输由约270KB压缩到约72KB；单字文件压缩后约0.3–2.2KB。用户已确认原收藏能看到题目、设置可点开。展示计时与家长验收模块均随页面内嵌，不增加启动请求；当前发布页 gzip 约81KB。

`node tools/build-glyph-files.cjs` 从原167字形重建 `glyphs/`、小目录 `glyph-catalog.js` 和完整校验清单 `data/glyph-manifest.json`。167个字形完整对象、原部件依赖保持不变，加载方式不改评分规则。`glyph-loader.js` 只有在目标及其原部件全部就绪后才交给评分，不能静默降级为整字判断。未缓存字首次需联网，下载后按字形版本缓存即可离线使用；超时保留笔迹、不记写错，按钮恢复可点。存档和笔迹记录的存储键保持不变。

音效或句子模块缺失/异常不会中断按钮或学习流程。只有家长新增的非内置字才访问第三方字形源；6秒超时覆盖响应正文。后台预热失败不影响首题。家长未解析成功的输入会保留，拼音表暂未加载时不会静默丢弃；小目录包含原167字的全部读音，保留多音字选择。

## 练习反馈、句子与家长优先

- 教学示范按现有字形的笔画数计算时长，不另下载分类表。首轮 `min(12, max(5, round(5 + max(0, 笔数 - 6) × 0.4)))` 秒；后三轮为首轮的60%、20%（取整）和0秒盲写。历4笔、收6笔保持5→3→1→0秒；辩16笔为9→5→2→0秒；警19笔为10→6→2→0秒。参数是待实际使用调整的初始产品设置，未验证教育效果。只在字形完成渲染并经过绘制机会后开表；切题、取消、同字重开时旧请求和旧计时不得覆盖新题。
- 每次写对有短促魔法音和星光；写错有柔和的门锁受阻音。只有首次独立写对或延迟复测通过，才显示“今天这个字学会啦，改天再考。”并播放胜利音。跟着示范写对或刚进入延迟复测，不会提前宣布通过。音效不依赖网络或音频文件，触笔解锁，切题清理；音频不可用时练习照常运行。动效不拦截笔尖，支持系统减少动态效果设置。
- 小喇叭旁新增“句子提示”，点后只朗读，不在书写界面显示答案。`sentence-hints.js` 为92个教材词、旧版词语和常见词配有原创短句，按完整词语区分同音词。家长可逐字选填句子，也可在导入队列中补充或修改；陌生词不会强行套用其他词的句子。
- 单字和批量加入共用导入逻辑：最新一批按输入顺序置顶、按字去重，立即保存；同字只更新提示与排队，不重置历史、掌握天数、复习时间或当日错题数。已经掌握或今天已经通过的字，也可明确重加复习。当天错满三次的字仍先等家长点“我讲过了”。
- 今日优先高于普通抽题和已就绪延迟复测；未完成的导入队列超过默认数量时，继续练完队列，不改变家长设置的日常目标。排队到次日不再抢优先，学习记录照常保留。已经正式通过的字当天不再随机出现，显式重加可以再次练习。每次导入有独立请求标识，旧题结束不能误完成家长刚重加的新请求。
- 设置关闭时，只替换尚未动笔的普通题；已经动笔或正在教学就先完成当前字。更换空白题不会虚增延迟复测的间隔。

## 家长识别验收（2026.11.03.5）

设置中的家长识别验收分两轮，每轮六次，供大人按照明确要求亲笔检查。每个字先完整写一次，再故意少写指定的一笔；按屏幕要求逐次进行：

| 次序 | 第一轮 | 第二轮 |
| --- | --- | --- |
| 1 | 完整写燕 | 完整写辩 |
| 2 | 燕少四点底中的一个点 | 辩少中间讠的点 |
| 3 | 完整写类 | 完整写历 |
| 4 | 类少米左上方的点 | 历少里面力的撇 |
| 5 | 完整写逃 | 完整写收 |
| 6 | 逃少走之旁最上方的点 | 收少右边攵最上方的短撇 |

每次提交后，大人须明确确认是否确实按本题要求书写。只有确认后，完整字才标为人工预期通过，指定缺笔才标为人工预期拒绝。系统原判独立保存，不能用系统判定反推人工标签。没有按要求写或无法确定的提交，人工标签保留未知，不计入符合率，留在当前题重新写；已经确认的误判照实保留，即使继续下一题也不能覆盖。

验收会话及笔迹须与孩子学习进度隔离，不增加今日通过数、学习历史、掌握天数、错题次数或场景奖励，也不完成家长优先请求、不消耗延迟复测的间隔。异步判分中的进入、退出、换轮和重复点击必须受保护，旧会话的结果不能写入新题；人工确认必须绑定刚才那份已冻结的笔迹。`parent-validation.js` 只负责题序、显式人工确认和结果汇总；页面接入负责异步令牌、笔迹保存及学习进度隔离。验收笔迹使用独立本地键 `hanzi-magic-door-parent-ink-v1`；不上传。会话只在内存中运行，刷新回到普通学习；已保存的验收笔迹仍可读取。

每轮“6/6”只说明这六份已人工确认的指定写法与系统判定一致。两轮识别验收完成后，仍须另外验收孩子的首次默写、教学展示与计时、盲写、穿插后的延迟复测、三次错误停车、跨日保存恢复和家长优先队列。识别验收不能等同完整教学流程已经通过，也不能据此认定游戏已经适合孩子独立使用。成人指定样本的符合率不代表真实孩子书写的整体准确率。

## 学习范围与选题

学习对象已从八个复杂测试字切换为**统编人教版三年级下册**。依据2025年10月第1版课本末尾的271词表，核对选取92个不同词、每词一个目标字，形成下一轮验证池；覆盖八个单元与七类结构：独体、左右、上下、半包围、全包围、左中右、上中下。这是92词验证池，不是整册271词全量默写。每格仍写一个字，词语用于上下文提示。

普通自由题每五个的软目标为少笔2个（不超过6笔）、中等2个（7–12笔）、多笔1个（至少13笔），同等条件下随机，并尽量搭配不同结构、避免本轮重复。到期复习、家长指定和延迟复测优先于搭配配额；候选不足时正常降级。大规模新字不会淹没真正到期的旧字。

字库版本升级到5，保留旧字学习记录、家长词语/读音、每日数量、场景和优先队列。旧测试字不再进入默认轮换，原判分代码保持逐字一致。独立补充88个字形，原79字的文件、数据及对象不覆盖。已核对的本地字形共167个，92个教材目标字均可按需加载并缓存。

数据、来源、重建：

- `curriculum-data.js` 与 `data/grade3-targets.tsv`：92词目标字及词中读音、结构、笔数；“李子”的子和“厉害”的害按词中轻声标注。
- `data/grade3-word-sources.json`：教材版本、271词原表、课号、单元和页码。词表印刷116–118页，对应PDF120–122页，已逐页核对原教材扫描件。
- `practice-selector.js`：只负责随机搭配，复习/教学状态机仍由页面管理。
- `curriculum-hanzi-data.js` 与 `data/curriculum-hanzi-manifest.json`：补充字形与冻结来源；许可证原文为 `ARPHICPL.TXT`。
- `node tools/build-grade3-curriculum.cjs`：从已核对源表与目标清单重建运行词库，不修改字形或判分。

教材官方入口：https://book.pep.com.cn/1211001302251/ 。原教材扫描件的托管来源：https://www.lejiaoku.com/resources/120 。

## 当前开发状态

课程切换本身不改变识别。第三轮针对辩、历、收，第四轮针对燕、类，第五轮针对颜增加有限判断；其余字的原有匹配流程和全局评分门槛不变：

- 辩按左辛、讠、右辛核对，为整字误拒提供补充解释；原判断通过时仍保留，避免拒绝已可用的断笔写法。不会据此声称解决辩的所有缺笔漏洞。
- 历按顶部厂横、厂撇、内部力核对，不能借外面的笔画拼出里面的力。只在历的区域内允许补充断笔解释：端点相距不超过区域对角线3%，拼后原位置的整条曲线质量至少0.85、平均距离不超过区域对角线6%；原有其它字的重接规则不变。
- 收同时要求原整字判断与左丩、右攵结构确认通过，避免放行错误重接，也不因局部分区增加原本拒绝的错误字。
- 第四轮修复燕的倒序连写：先沿用旧判断，旧判失败且至少14笔时，才尝试受限解释，只允许口的参考5..6和北右参考10..11两组连接。北右按两种书写顺序分段核对，各段须通过原单笔门槛、真实钩须存在且方向正确；口须通过原位覆盖。不会因人工拼接参考轨迹的尾向而误拒，也不允许凭空增加第三组合笔藏住缺笔。不可行分区提前跳过，避免重复昂贵配对。
- 第四轮类按米／大分别对齐，容忍下部大横较短；仅米第0笔点在完整六笔区域、未合并或重接时按位置／长度核对，保留原1.7倍长度上限，并要求它最靠近自己的参考位置。第1笔短撇与其余笔仍检查形状和方向，未放松全局门槛。
- 第五轮颜：只在原判失败且过滤后恰有15笔时补充核验。左上点写得稍长、近竖会触发原短点长度惩罚，导致它与右短撇换配。补充核验要求15笔没有完整重描、唯一短点在自己的位置；只准修正原点／右短撇两行，其他13或14行保留原配对和质量，同时禁止彦／页跨区借笔。沿用原重描检查、评分门槛和普通匹配，不扩大整体容差；原先通过的书写直接保留。确认的15笔原迹通过，首次12笔仍被拒，后者人工标签维持未知。
- 2026.11.04.1修复仰的缺笔放行：先保留原判为必要条件，原判通过后再要求存在完整的严格连笔覆盖解释；两笔连接可用任一书写顺序，仍核对每段的形状、相对位置和钩形。仅增加拒绝条件，不把原失败改成通过；允许重新寻找完整解释，保住旧配对选错但实际完整的合法连笔。其他字、全局门槛与167字形不变。
- 普通自主写字、教学、复测完全空白时点击“写好了”，现在提示先写字，不评分、不计错、不跳步或改计时。单点、短笔等非空输入仍按原规则评分并保存诊断。此前完全空白会计为错误却不留笔迹，可能造成尝试次数与留存笔迹数不同，但不能据此认定某次历史缺失的原因。
- 逃第四轮只有第1与第4次被拒，分别涉及兆左侧小笔写长／上挑或写平，第1次的辶顶点也偏长。用户明确记不清所指次数，六条均保留未标注，本版未改逃的判断，也不宣称已修复该未知例。
- 慧、警、澡、薄先按空间结构分部件，再核对笔画；不要求按标准笔顺书写。
- 警的“言”继续分成点、三横、口，避免别处的笔画顶替缺笔。
- 第二轮又将警的“句”分成勹和内口，允许内口相对外框写小、连写，保留原评分门槛；修正了家长指出的倒数第二次误拒。
- 八个测试复杂字的连笔需要在部件原位置覆盖相应笔画，不能把局部短线单独移位、放大后冒充多笔。
- 已确认三点水结构后，允许前两点写成短划；第三笔仍检查形状，多一点或过长点没有豁免。
- 新笔迹同时保存版本和提交时间，旧存档与旧笔迹继续兼容。第2版笔迹格式新增 `rawS`，原值保存全部输入点（含被过滤的小点），保留旧 `s` 摘要供旧工具读取。原16点取整摘要会让本轮最后一个收在重放时翻转判定；重放新记录必须优先使用 `rawS`，不能据摘要翻转宣称修复成功。
- 记录及导出新增可选 `phase`：首次默写、教学／轮数／步骤或复测。旧记录不补造阶段，仍可读；阶段元数据不参与评分，帮助以后定位“教学过程中”的争议。
- 笔迹日志以200条和约2MiB本地存储预算为软目标，按整条清理最旧未标记记录，保护最新及人类标记，不再抽稀原点。配额失败不阻止判分，提示保留到打开设置时；标记按钮绑定显示记录，异步新增或清理不会导致标错新条目。
- 新增过滤诊断：保留单点、短笔被删除前的轨迹、长度与采样点数，不改变判分用的笔迹。第二轮澡的一条拒绝记录只有一点一提；旧版不保存被删笔迹，因此不能确定是实际漏点、采样没收到，还是短点被过滤。此轮增加证据，不宣称已修好这次澡。

29条有明确人工判断的真实样例均符合预期（原22条、第三轮3条、第四轮3条、第五轮颜1条）；47条未确定人工标签的笔迹单独保留，不计入正确率。第三轮其余11条新旧重放判定均未改变；辩有一条旧摘要的重放结果与设备当时不同，原始点已丢失，不据此补标签。第四轮17条中仅燕最后一次、类第一次与倒数第二次人工明确正确，均修正；其它14条判定保持。新记录17/17能原值重放，坐标、摘要及过滤信息一致。“薄”的三次完整笔迹均通过候选重放，但用户反馈与具体次数不能完全对应，因此未擅自添加人工标签。第二轮澡已明确指记录B（round2-05），用户怀疑小点没有录上；过滤前原始笔迹不可恢复，未擅补书写对错标签。
